# 🚀 Signal Routing, Timing Closure & GDSII Generation

## 📖 Overview

In this focuses on the final implementation stage of the ASIC Physical Design flow using **Cadence Innovus**. During this stage, the placed and clocked design is transformed into a manufacturable physical layout through signal routing, timing verification, and GDSII stream-out.

The objective is to complete the physical implementation while ensuring timing closure, clean design rule checks (DRC), and successful generation of the final GDSII database.

---

# 🎯 Objectives

- Complete global and detailed signal routing
- Verify post-route setup and hold timing
- Check design rule violations (DRV)
- Generate the final GDSII layout
- Validate design readiness for fabrication

---

# 🛠️ Design Flow

```
Clock Tree Synthesis
```
