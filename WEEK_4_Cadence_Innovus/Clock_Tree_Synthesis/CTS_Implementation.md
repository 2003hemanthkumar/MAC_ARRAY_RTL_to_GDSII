# 🌳 Clock Tree Synthesis (CTS)

## 📖 Overview

Clock Tree Synthesis (CTS) was performed after placement to construct an optimized clock distribution network for the MAC Array.

The objective was to minimize clock skew, balance clock latency, and improve timing quality before detailed routing.

---

## 🛠 CTS Implementation

The following operations were performed:

- ✔ Clock Tree Specification Generated
- ✔ Clock Buffers Inserted
- ✔ Clock Network Optimized
- ✔ Clock Routing Completed
- ✔ Clock Tree Verification Performed

---

## 🎯 Objectives Achieved

- Balanced clock distribution
- Reduced clock skew
- Improved setup and hold timing
- Prepared the design for routing
