# 🚀 Cadence Innovus – Physical Design of MAC Array

> **Complete ASIC Physical Design Flow | RTL-to-GDSII Implementation | Cadence Innovus**

---

## 📌 Project Overview

This repository demonstrates the complete **ASIC Physical Design** implementation of a **Multiply-Accumulate (MAC) Array** using **Cadence Innovus**.

Starting from a synthesized gate-level netlist, the design is implemented through the industry-standard backend flow, resulting in a final **GDSII** layout ready for fabrication.

---

## ⚙️ Design Flow

✔️ Design Import

✔️ Floorplanning

✔️ Power Planning (Rings & Stripes)

✔️ Special Routing (SRoute)

✔️ Standard Cell Placement

✔️ Placement Optimization

✔️ Clock Tree Synthesis (CTS)

✔️ Signal Routing (NanoRoute)

✔️ RC Extraction

✔️ Static Timing Analysis (STA)

✔️ DEF Generation

✔️ GDSII Stream-Out
